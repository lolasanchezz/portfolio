the public facing website for sunbeam. currently a post-mortem, and has stats on the website on the event!

sunbeam was my first project at hack club. i was helping organize it before i was officially on the pay roll. i was mostly in charge of getting signup + the backend set up, and having an admin dashboard to see all the events. it was mostly a typical full-stack app written in react, but the impressive aspects were the numbers - this app handled 1000+ signups, with mulitple other data points being collected in the signup, which made me learn a ton about database structuring. i used airtable, a mysql-esque relational database, using the typical tables and fields. 

i learned something pretty important - you can always add more fields to a table, but you can never combine tables cleanly!
